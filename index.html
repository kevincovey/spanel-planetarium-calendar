Weekly Defaults

Define your typical week: which timeslots run on which weekdays, and the default staff for each. These flow into a new quarter when you click Generate quarter (in Setup). Uncheck Active to skip a slot.

Quarters

A quarter is a 3-month window. Set one up, then generate its show slots from your weekly defaults. To start a new season, add another quarter — old ones stay in your history.

Cloud sync & sign-in (Supabase)

  1. Create a free project at supabase.com.
  2. In the Supabase SQL Editor, paste schema.sql and click Run.
  3. Add each staff member under Authentication → Users → Add user.
  4. Open Project Settings → API, copy the Project URL and the anon public key, paste below, Connect.

Subscribable calendar feeds

The app publishes two live feeds:

  • Availability (availability.ics) — open slots only, marked "Available", with no personal info. Safe to embed on the planetarium's public website.
  • Staff (staff-calendar.ics) — tentative & confirmed shows so staff know when they're needed in the dome. Includes group/focus/staffing but never contact names or emails.

Two ways to produce them: the ⬇ Availability .ics / ⬇ Staff .ics buttons on the Calendar tab (one-time snapshots), or the included GitHub Action which rebuilds both on a schedule for live subscription. Subscribe to https://YOURNAME.github.io/REPO/<file>.ics. Full steps in README.md → “Subscribable calendar feeds”.
